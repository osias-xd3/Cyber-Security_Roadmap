How To Use This Roadmap: The Parallel Loop

Cybersecurity skill-building is not a straight sequential line — it is three parallel engines running at increasing intensity. Don't wait to "finish" networking before touching Linux, and don't wait to "finish" studying before doing your first TryHackMe lab.

Curriculum Foundations

Course Basics & Core Knowledge Areas

Most beginners fail because they jump into "hacking tools" before understanding how networks and operating systems function. This roadmap fixes that foundation.

1. IT & Networking Deep Dive

Master how packets traverse the internet: the OSI 7-layer model, TCP/IP, IP subnetting, DNS resolution, DHCP leases, common ports, routers, and firewalls. Without this, security tools are just magic black boxes.

2. OS Internals & Systems Admin

Navigate the Linux command line cold with bash, file permissions, and directory structures. Understand Windows Active Directory, Group Policies, Domain Controllers, and Event Viewer logs.

3. Core Security Models & Defense

The CIA Triad, threat modeling, AAA/IAM, cryptography (symmetric, asymmetric, hashing, PKI), common exploits (phishing, malware, SQLi, XSS), and incident response lifecycles.

4. Hands-On Ranges & CTFs

Theory alone will never get you hired. You will practice real commands in TryHackMe, Hack The Box, OverTheWire Bandit, and PortSwigger Web Security Academy from month 2 onwards.

5. Verified Free & Paid Certs

Fact-checked for 2026. Avoid expired free voucher traps (like the closed ISC2 CC program). Learn how to earn active free badges (Fortinet, Cisco, AttackIQ, Centri) while saving for CompTIA Security+.

6. Public Portfolio & SIEM Lab

The difference between getting an interview and being ignored. Learn how to publish GitHub write-ups, run your own virtual home SIEM (Splunk or ELK), and document technical progress publicly.
